## 启动

有两种用法，用的是同一个程序、同一套功能：

### 桌面版（Windows）

有安装版和免安装版，功能一样：

- **安装版** `Tetra-Setup-<版本>.exe`：中文安装向导，可以选
  - 安装位置（默认 `%LOCALAPPDATA%\Programs\Tetra`，可以换到任何文件夹）；
  - 只为自己安装（不用管理员权限），还是为这台电脑的所有用户安装；
  - 要不要桌面快捷方式、要不要开机自动启动。

  开始菜单里会有 Tetra。卸载在 Windows 的「设置 → 应用」里，卸载时会问要不要连数据一起删（默认保留，重新安装后接着用）。升级直接运行新版本的安装程序。
- **免安装版** `Tetra-<版本>-windows-x64.zip`：解压到任何文件夹，双击 `Tetra.exe`。第一次打开会问要不要在桌面和开始菜单放快捷方式（只问一次）。

打开以后：

- 不用装 Python，也不用开终端。窗口是 Windows 自带的 Edge 以“应用”模式打开的（没有地址栏和标签页），用单独的浏览器资料目录，不影响你平时用的浏览器。没有 Edge 时用 Chrome；都没有时用默认浏览器打开，再显示一个小窗口，关掉它就退出。
- 再双击一次只会再开一个窗口，不会起第二个服务。
- 关掉窗口就退出；还有题在出、或者浏览器里还开着 Tetra 的页面时，后台接着跑，都结束了才退出，题不会出到一半丢掉。
- 题库、试卷、对话、设置和 API Key 默认存在 `%LOCALAPPDATA%\Tetra\data`（日志在 `%LOCALAPPDATA%\Tetra\logs`），升级不会丢。
- 第一次运行没签名的程序时，Windows 可能提示“已保护你的电脑”：点“更多信息”→“仍要运行”。

**桌面版的设置**（左下角头像 → 个人设置 → 桌面版，只有桌面版里有这一页）：

| 设置 | 说明 |
|---|---|
| 开机时自动启动 Tetra | 登录 Windows 后自动打开；可以再选“开机启动时窗口最小化”，只在任务栏里出现 |
| 桌面快捷方式、开始菜单快捷方式 | 随时加上或去掉。为所有用户安装时建的快捷方式要管理员权限才能删 |
| 导出的 Word、PDF 存到哪 | 默认“文档\Tetra”，点“选择文件夹…”换成别的；导出后右下角可以点“打开”“打开文件夹” |
| 每次导出都问存到哪 | 打开时每次弹出“另存为”，自己选位置和文件名 |
| 数据文件夹 | 点“更改…”选一个空文件夹（或者以前放过 Tetra 数据的文件夹）；点“现在重新打开 Tetra”或下次打开时，数据复制过去，以后用新位置。原来的文件夹原样保留 |
| 出了问题 | 打开日志文件夹、程序所在的文件夹 |

**同时用网页端**：桌面版开着时，用任何浏览器打开 http://127.0.0.1:8765 （8765 被占用时往后顺延）就是同一个 Tetra；左下角菜单里的“在浏览器中打开”也会用默认浏览器打开它，地址写在那一项下面。

### 从源码运行（网页端）

```bash
tetra
```

启动服务并打开浏览器（http://127.0.0.1:8765）。关掉终端窗口或按 Ctrl+C 停止。从源码运行时，数据在项目的 `data/runtime/` 里，和桌面版的数据是分开的（想共用，把 `TETRA_HOME` 设成同一个文件夹）。

| 命令 | 作用 |
|---|---|
| `tetra --port 9000` | 换端口；8765 被占用时也会自动换到下一个空闲端口 |
| `tetra --no-browser` | 不自动打开浏览器 |
| `python -m pip uninstall tetra-mingti` | 卸载启动命令 |

- 第一次运行时，`tetra` 会在项目里建 `.venv`，按 `requirements.txt` 装好依赖；默认下载源失败时，自动改用官方 PyPI 再试。以后只有 `requirements.txt` 变了才重新装。依赖都装在 `.venv` 里，不会装进系统的 Python。
- 服务已经在运行时，`tetra` 只打开浏览器。
- 服务停了的话，页面顶部会提示“连不上服务”，每隔几秒重连一次；重新运行 `tetra` 后页面自动恢复，不用刷新。

不想装命令，可以双击 `启动命题智能体.bat`（同一个启动器），或者手动运行：

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run.py
```

## 接入模型

打开页面后进入「个人设置 → 模型服务」，点“接入模型服务”：

- 选一个模板（DeepSeek、智谱 GLM、OpenAI、Claude），填上 API Key 就能用；其他兼容 OpenAI 接口的服务（通义千问、Kimi 等）填接口地址和 Key。
- 可以一键测试连接，从服务获取模型列表，给型号起显示名称（比如“快速模型”“增强模型”）。可以接好几家，保存后马上生效，不用重启。
- 主模型、把关模型在「出题方式与模型」里选。
- 配置存在 `data/runtime/models.json`。Key 只保存在这台电脑上，页面上只显示头尾几位。也可以照 `.env.example` 写进 `.env`，第一次启动时会自动搬进界面，名为“默认服务”。

## 界面

三栏布局，分隔条可以左右拖动，双击恢复默认宽度。

- **左栏**：新对话、题库、试卷、对话列表；左下角是个人设置。在对话上点右键可以：
  - 重命名；
  - 置顶：标题前出现小图钉，排在最前；
  - 删除：在菜单里再确认一次。删掉的是这个对话的记录，出好的题和组好的试卷都还在；题出得不好时，可以勾选“同时从题库删掉这里出的题”一起删（已经组进试卷的题会保留）。还有题在出的对话不能删。
- **中间**：对话。出题、聊天、组卷、识题按先后排在一起。
- **右栏**：题目或试卷预览。这里只放给老师用的题目本身，审题、复核这些过程信息留在中间。

## 出题

- 输入框里直接说要求，比如“以二十四节气为情境出一道三角函数应用题，要配图”；也可以只选下方的考点、题型、难度、题量、用途，空着输入框发送。
- 下方这几项默认都不选：
  - 没选的按个人设置里的默认；年级先看考点所在的年级，再看任教年级。不选考点时，由模型在这个年级的范围里挑一个，并避开最近出过的考点。
  - 选了的只管下一次出题，题出完就恢复成不选；也可以用菜单最上面的“不指定”清掉。
- 出题时按角色列出进度。出完可以在输入框里接着说，或者点“再出一道同类题”“难一点”“简单一点”“换个情境”。一次出几道时，每道题单独出、单独审核，互不重复。
- 偶尔没出成时，点“再试一次”或“简单一点再试”：这次没出成的原因和最后一版题面会一起交给命题员，避开同样的问题，而不是原样重来。
- 点“停止”会当场断开正在进行的模型请求，不用等这一轮调用结束。一次出几道、自动组卷和识题导入也一样。
- **同时出好几道**：一道题还在出时，可以点“新对话”接着出下一道，或者在同一个对话里接着说；每件事各出各的，侧栏里正在出题的对话前面有个小圆点。别的对话里的题出好了，右下角会提示是哪个对话。整个服务同时最多出 8 道（环境变量 `MAX_RUNNING_JOBS` 可以改），再多的排队。
- 输入框下方选的考点、题型、难度这些只管刚发出的那一次：发出去就恢复成不选，接着出下一道时不会沿用；每道题用的设置写在它的任务卡片上。
- 复核员退回时，解题员按意见只改出错的步骤，过程记录里能看到每轮改了什么。到了调用次数或时间上限，会交付最好的一版并标“待核对”，题目上写明还没解决的意见；这样的题不会被自动组卷选用，修改保存后标记去掉。
- 每道题都能回放整个出题过程（压缩到 20 秒左右）。过程记录里能看到每条审题意见、退回原因，以及每次模型调用的耗时和 Token。

## 聊天与识题

- 打招呼、问知识点、请它讲题、问题库里有什么，都直接回答（支持公式和 Markdown）。出题、组卷进行中也可以接着聊。
- **附件**可以直接粘贴、拖进输入框，或者点回形针选：
  - 支持 PNG / JPEG / WebP / GIF 图片、PDF、.txt / .md 文本；
  - 每个最多 25 MB，一次最多 10 个。
- **解题**：说“这道题怎么做”，助手看图（PDF 按页渲染，最多看 8 页）直接解答。当前模型不能看图时，会自动换一个已接入、能看图的模型。
- **存进题库**：说“把这几道题存进题库”：
  1. 助手逐页识别出题目：题干、选项、答案、解析、考点；
  2. 原题没有解析的，由模型补写一份，标“助手补写”；
  3. 在对话里列出每道题和解析，选好存到哪个文件夹，勾选后点“存入题库”才保存，也可以点“不存了”。
- **把前面的题存进题库**：先让助手解了一道题（发图片或者打字都行），再说“把这个题整理到题库中”，不用重新发图：
  - 助手把对话里的题和前面写好的解答整理成题库的格式；原图还在（4 小时内、服务没重启过）时题干照原图录，配图从原图上截；
  - 解析用的是对话里的那份解答：对话里解错了，卡片上也是错的，存之前看一眼；
  - 说了“存到某某文件夹”时，核对卡片上已经选好那个文件夹（没有就新建）。
- 出题流程出好的题已经自动在题库里，不用再存。
- 附件原文件只在服务运行期间保留 4 小时；对话记录里只留缩略图和识别结果。
- **整理题库**：直接说“新建一个期中复习文件夹，把导数的题都放进去”“按章节帮我把题库分好”“把刚才出的几道题放进周测文件夹”。助手当场建好文件夹、把题放进去，在对话里列出改了什么；点“撤销”恢复成整理之前的样子，点“在题库里查看”打开那个文件夹。助手只整理文件夹，不会删题、改题。

## 自动组卷

说一句“从题库中自动选择合适高一期末考试难度的试题，给我组一套试卷”，助手分四步组卷：

1. **定方案**（双向细目表）：按要求、当前学期和教材目录，定考查范围、题型结构，以及每道题的知识点、难度和分值。没说结构时按新高考数学卷：单选 8、多选 3、填空 3、解答 5，满分 150 分，考试 120 分钟。
   同时按你的说法定**题目从哪来**，写在方案里：
   - 说了“原创”“全新”“不要用题库里的题”，或者是“出一套……卷”这类要它出题的说法：全部现场出新题，不用题库；
   - 说“组卷”“挑题”“从题库里……”：先从题库挑，不够的现场出；
   - 说“只用题库里的题”：不现场出，挑不到的空着，组好后可以在试卷里补。
   组好的卷子用了题库里的题、其实想要全新的，点“全部换成新题”：按同样的要求再组一份，题目全部现场出。
2. **从题库挑题**（全部原创时跳过）：
   - 题型相同，难度最多差一档；
   - 知识点先找同一个考点，再放宽到同一节、同一章；
   - 一个考点在一份卷子里只用一次，没进过别的试卷的题优先。
3. **现场出题补缺**：题库里没有合适的题，就按方案走完整的出题流程，同时出 2～3 道。没出成就降一档难度再出一次，还不成就从题库里找一道同题型的题顶上（全部原创时不用题库的题顶，改为再出一次）。
4. **组成试卷**：用标准试卷版式（版头、注意事项、大题说明，答案和双向细目表另起一份），存进“试卷”，可以直接导出 Word / PDF。

实测：一份“单选 4、填空 2、解答 1”的集合与函数小测验，从题库挑中 5 道、现场出 2 道，共用 84 秒、26 次模型调用。

## 题库与试卷

**题库**：出好的题自动收进来，按“册 › 章 › 节 › 考点”分类，能做这些事：

- 搜索，按题型和难度筛选；
- 修改题干、选项、答案和解析，公式用 `$…$`，边改边预览；
- “精简解析”：把解析整理成标准答案的写法；
- “配图 / 改配图”：写一句要求，让配图员重画；
- 导入试卷、讲义的 PDF 或照片：模型逐页识别，跨页的题和解答自动接起来，配图从原文件上截下来，老师核对、勾选后收进题库；
- **文件夹**：自己建分类，可以一层套一层（最多 5 层）。
  - 列表上方第一行是所在位置（全部题目 › 期中复习 › 函数），第二行是下一层的文件夹和“未归类”，数字是里面有几道题；
  - 移题：把题拖到文件夹上（勾选了几道就几道一起走），或者勾选后点“移到文件夹”，也可以在右栏点“移到”；拖到“未归类”就移出文件夹；
  - 文件夹右键（或位置栏里的“⋯”）：打开、重命名、新建子文件夹、删除；文件夹也能拖进别的文件夹；
  - 删文件夹不删题：里面的题和子文件夹挪到上一级；
  - 看“全部题目”时，每道题旁边标着它在哪个文件夹。

**试卷**：

- 在题库里勾选题目组卷，或让助手自动组卷；
- 按题型自动分大题，题号连续；可以改标题、考试时间、分值和顺序；
- 版式可以选练习卷或标准试卷（高考版式）；
- 右栏是和导出结果一致的 A4 预览；
- 导出 Word（公式是 Word 原生公式，能直接改）或 PDF，也可以直接打印；打开“附答案与解析”时，答案另起一页。

## 思考强度

点输入框右下角的模型名，在菜单里拖滑块调。分四档，默认是中，可以在「出题方式与模型」里改：

| 档位 | 出题 | 聊天 |
|---|---|---|
| 低 | 都不开思考，最快、最省 Token | 判断意图时顺手写好回答，一次调用 |
| 中 | 只在构造题目、改题和规划解法时思考 | 用模型最轻的一档思考 |
| 高 | 构造、独立求解、规划、复核都思考；写解析段落这类大量调用不开 | 正常思考 |
| 极高 | 和高一样的几步，用模型最深的一档；单次调用最多等 10 分钟 | 最深的一档 |

OpenAI 没有最深一档时，极高会退到 xhigh 或 high。

出 4、5 星的较难题和压轴题时至少用高：滑块选了低或中，也按高出，服务端同样会改。这一条只管出题，聊天始终按滑块选的那一档。

## 上下文

每个对话都有上下文记忆：助手回答、整理出题要求、定组卷方案时，都会带上前文。

- **怎么算前文**：按“轮”算，一问一答、一道题、一批题、一次组卷、一次识题各算一轮。从最近的一轮往前带，最多约 2.4 万 Token。
- **压缩**：输入框右下角的小圆环显示用量，点开可以手动压缩：最近 4 轮以前的内容会写成一段摘要。用量超过 85% 时，一轮结束后会自动在后台压缩。
- **估算**：Token 按字数估算（中文每字约 0.65 个），只用来显示用量和决定什么时候压缩。

## 个人设置

| 分组 | 内容 |
|---|---|
| 个人资料 | 称呼、头像（上传后裁成正方形，存在本机）、任教年级、教材版本（人教 A 版 / B 版，2019 年版） |
| 外观与语言 | 主题：白天 / 夜晚 / 跟随系统；语言：中文 / English |
| 出题偏好 | 默认题型、难度、用途，解析详略，每道题都带上的要求 |
| 模型服务 | 见[接入模型](#接入模型) |
| 出题方式与模型 | 快速出题 / 多一道把关 / 最严格 / 自定义（方案数、是否验算、把关模型），默认思考强度 |
| 偏好学习 | 默认关闭；按出题记录提建议，点了采用才生效 |
| 数据与隐私 | 导出 JSON（不含 API Key）、删除全部偏好 |

设置保存在 `data/runtime/profile.json`。
