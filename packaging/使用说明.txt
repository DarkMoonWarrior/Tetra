Tetra 命题智能体 · 桌面版

【安装】
两种都行：
- 安装版：双击 Tetra-Setup-<版本>.exe，按向导选安装位置、要不要桌面快捷方式和开机自启。装好以后在
  Windows 的「设置 → 应用」里可以卸载。
- 免安装版：把 zip 解压到任何文件夹，双击里面的 Tetra.exe。第一次打开会问要不要放桌面快捷方式。
不用装 Python，也不用开终端。窗口用的是 Windows 自带的 Edge 浏览器内核。

【桌面版的设置】
左下角头像 → 个人设置 → 桌面版：开机自动启动（可以最小化）、桌面和开始菜单快捷方式、
导出的 Word / PDF 存到哪个文件夹（或者每次都问）、数据文件夹放在哪。

【第一次用】
点左下角的头像 → 个人设置 → 模型服务，选一家（DeepSeek、智谱、OpenAI、Claude 或其他兼容服务），填上 API Key。

【网页端】
程序开着的时候，用任何浏览器打开 http://127.0.0.1:8765 也是同一个 Tetra，题库、对话都一样。
左下角菜单里也有“在浏览器中打开”。（8765 被别的程序占用时会往后顺延，菜单里写着实际的地址。）

【关闭】
关掉窗口就退出。还有题在出、或者浏览器里还开着 Tetra 的页面时，会在后台出完、等页面关了再退出。

【数据放在哪】
题库、试卷、对话、设置和 API Key 都只存在这台电脑上，默认在 %LOCALAPPDATA%\Tetra\data
（在资源管理器的地址栏里输入 %LOCALAPPDATA%\Tetra 就能打开），可以在「设置 → 桌面版」里换位置。
升级时直接运行新版本的安装程序（免安装版就把 Tetra 文件夹整个换掉），数据不会丢。

【遇到问题】
日志在 %LOCALAPPDATA%\Tetra\logs\tetra.log。
Windows 第一次运行没签名的程序时可能会提示“已保护你的电脑”：点“更多信息”→“仍要运行”。
